# Code review

1. Identify the scope (paths, PR intent, or pasted diff).
2. Check correctness, edge cases, and failure handling.
3. Call out security and data-loss risks.
4. Suggest focused tests when coverage is thin.
5. Return a short list of findings, severity first.
